# Agape Farmstead Proposal

Interactive proposal decks for Agape Farmstead: an SEO pilot, Thanksgiving delivery inside 200 miles of Nashville, and a five-year brand direction.

GitHub Pages: https://sharpninja.github.io/agape-farmstead-proposal/

```bash
npm install
npm run dev
```

The dev server listens on port 8080. `npm run build:pages` writes a static site to `gh-pages/`.
